# Wayfarer v1.2 — Celestial PolyCodex / Moonlight Cavern

Version 1.2 turns the v1.1 PolyCodex from a presentation-only resonance wheel into a server-owned gameplay system and grows the Reedhaven/Ashfen rehearsal realm with an original Celestial Observatory and Moonlight Cavern art layer.

## Authority boundary

The server remains the authority for player identity, position, collision, timing and snapshots. PolyCodex casts now cross the same action boundary as combat, practice and skilling. The client submits only a canonical three-rune chord. The server validates range, cooldown, cast-count bounds and player state before publishing the result.

The current realm fixed tick remains **50 ms**. v1.2 bumps the compatibility contract to:

- protocol version 2
- simulation revision 16
- scene revision 3
- snapshot version 1

Old simulation contracts are rejected rather than silently interpreted as v1.2.

## Authority-backed PolyCodex

The twelve original resonance nodes remain order-independent and deterministic. Successful server casts award **8 Magic XP + 8 Runecrafting XP**, persist cast/cooldown state in player save version 6, and arm exactly one bounded attunement. The attunement is consumed by the next matching successful authoritative action:

| Attunement | Consumed by | Authoritative reward |
| --- | --- | --- |
| Lantern Bloom | Woodcutting | one bonus resource + 10 Woodcutting XP |
| Pathfinder's Gleam | Agility practice | +10 Agility XP |
| Miner's Echo | Mining | one bonus resource + 10 Mining XP |
| Tide Whisper | Fishing | one bonus resource + 10 Fishing XP |
| Ward Glimmer | successful guard | +10 Defence XP |
| Starlight Trace | Magic practice | +10 Magic XP |

Gathering bonuses are atomic: the bonus is not consumed when the resource pack cannot accept it, preventing partial-capacity duplication. Resonance expires safely, cooldown is measured in server ticks, and old saves migrate with a clean resonance state.

## Celestial Observatory

The observatory is positioned at a deterministic walkable point near the starting settlement. It combines original low-poly geometry with the visual language of the supplied references:

- a twelve-sided stone/brass dais and twelve pylons
- cyan/violet/gold resonance gems
- three slowly orbiting celestial rings
- an open Codex lectern
- the floating dodecahedral PolyCodex and its twelve selectable rune nodes
- a Sunward Orchard of angular fruit trees and oversized sunflowers
- a Prism Dew garden of faceted leaves and reflective droplets

The observatory is more than decoration: server range validation uses the same deterministic Codex point exposed in `GameState.codex`, so the HUD, minimap, renderer and gameplay reducer agree on where a cast is allowed.

## Moonlight Cavern

The far landing is visually transformed into the Moonlight Cavern while preserving the authoritative navigation/gameplay reducer. Its original procedural presentation includes:

- dark low-poly cave ring and crystal seams
- cyan, violet and amber crystal formations
- moonlit water pool
- timber walkway and posts
- violet resonance portal
- warm lantern pools
- bioluminescent mushrooms
- a stylized astral snail as ambient fauna
- pulsing blue moonlight driven only by presentation time

The cavern renderer cannot award XP, move actors, change inventory, or mutate collision. Gameplay results still come from the realm authority. This intentionally keeps high-energy art direction separate from game-state trust.

## Image-to-game translation

The supplied images were used as inspiration layers, not copied assets:

- coastal orchard → Sunward Orchard saturation, fruit silhouettes, flowers and open-sky color energy
- crystal miner/lantern cave → cyan mineral seams plus warm amber work lights
- painted leaf/dew → Prism Dew faceted leaves and glass-like droplets
- enchanted library/open book → Codex lectern and archive-like stone/gold composition
- luminous snail/mushrooms → original astral snail and glowshroom fauna
- neon creature/ritual and orbital-observatory images → cyan/magenta/violet resonance rings and celestial machinery
- saturated mountain/castle images → stronger blue-violet night depth and amber architectural contrast

The meme reference is not reproduced; only its playful old-internet tone is compatible with optional future easter eggs.

## Rendering build bridge

The dependency-complete source of truth is `src/celestial-expansion-3d.ts` plus `src/realm-3d.ts`. The release also includes `tools/patch-v12-visual-bundle.mjs` as an optional deterministic fallback for environments that cannot install the Babylon/esbuild toolchain. In this continuation, Node 24.19 dependencies were installed and the canonical source build regenerated the Babylon bundles; the fallback is not used by the normal build.

On the required Node 24.19.x environment with dependencies installed, run `npm ci && npm run build`; the normal source build should replace the bridge-generated bundle.
