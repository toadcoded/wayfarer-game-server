# Wayfarer v2.6.0 integration report

## Scope

The stable Wayfarer release now includes the v2.6 hostile-world core and a client HUD for field encounters:

- Old Bell Grave: three skeletons and steel warhammer drops.
- Mirewake Hollow: three zombies and steel battleaxe drops.
- Broken Standard Camp: six hostile guards in a multi-combat camp.
- Server-authoritative melee styles, ranged arrows, magic runes, projectile impact ticks, aggro, leash, respawn, drops, and loot pickup.
- Backward-compatible inventory migration with a bounded steel-loot counter.
- Client target selection, melee style selection, ranged/magic controls, multi-combat status, and loot buttons.
