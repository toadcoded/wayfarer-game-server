# Wayfarer v0.7.2 — local transport rehearsal

A loopback-only client/server expansion of v0.7.1. Two browser tabs can join one server-owned Willowglass Causeway. This is an executable networking rehearsal, not a hosted MMO release.

## Start the shared realm

Node 22+ is required (verified with Node 24.19.0). Install the pinned dependencies, then start:

```sh
npm ci --ignore-scripts
npm run realm
```

Open http://127.0.0.1:8081 in two tabs and press **Join realm** in each. Use arrow keys or the on-screen direction buttons. Your marker is gold; other players are blue. Both players initially spawn at the same landing, so move to separate them. The server owns movement, collision, player IDs and time. The client draws authoritative snapshots at 10 Hz; interpolation and prediction are not implemented.

Use the exact 127.0.0.1 URL printed by the server. The host binds only to loopback and does not accept a different hostname or Origin. A second physical device cannot connect to this loopback server. Do not expose it through a tunnel or change the bind address as a substitute for production security.

Disconnect removes that player. Joining again creates a new player at the landing. It does not resume a saved character. Stop the server with Ctrl+C.

The server supports up to eight local connections. There are no accounts, passwords, remote services, database migrations, persistent saves, or automatic reconnection.

## Offline preview and tests

The original local preview remains available:

```sh
npm run preview
```

Open http://127.0.0.1:8080 for the three offline crossing styles, tap-to-move and pause controls. It runs without installing dependencies because compiled JavaScript is included. The network rehearsal needs the pinned ws dependency.

```sh
npm test
npm run demo:realm
```

Strict TypeScript compilation and 87 automated tests pass. The transport host is a Node ESM JavaScript adapter; it is exercised by integration tests, not included in TypeScript's source check.

## New wiring

- src/realm-scene.ts: one deterministic world recipe and collider setup for server and network client.
- tools/realm-server.mjs: loopback HTTP/WebSocket adapter, server-owned timer, per-recipient snapshots and cleanup.
- src/realm-client.ts and preview/realm.html: manual connection lifecycle, strict snapshots, direction input, authoritative avatar rendering and cached static scenery.
- test/transport.test.mjs: real socket integration and rejection cases.
- test/network-client.test.mjs: browser-client module exercised with a stub DOM and real WebSocket connection.

Existing terrain, construction, pathfinding, session rules and permanent fail-stop fault handling remain included. Original ZIPs are unchanged; reference-source branches remain excluded from compilation and execution.
