## Full-build limitation in this execution container

The repository requires Node `>=24.19.0 <25`; this container exposes Node `22.16.0`. A fresh `npm ci` also could not complete because the container cannot resolve `registry.npmjs.org`. Therefore a dependency-complete `npm run build` and the dependency-backed suites (`ws`, BabylonJS, PGlite and release-process tests) were **not rerun** for v1.1 here.

The checked-in v1.0 bundle remains present, so the new HTML/CSS/compiled client interface works with the existing renderer. The new Babylon dodecahedral PolyCodex source is included in `src/realm-3d.ts`; running the normal `npm ci && npm run build` under the required Node 24.19.x environment regenerates the 3D renderer bundle with that world prop.

## Authority boundary

Resonance is intentionally cosmetic/local in v1.1. It does not grant XP, damage, speed, loot, inventory, quest, movement, or persistence changes. Public chat is visibly marked unavailable until a real chat transport exists; the UI does not fabricate remote users.

The note/color/dodecahedral motif is fictional game design and is not presented as a medical or physical-science claim.
