# rc.8 readiness note

Xam is now integrated as a deterministic, server-owned autonomous trainer. This does not make Xam a production AI service and does not assert consciousness or sentience. No external model/API cost is introduced: skill scheduling, movement, micro-events, rewards and heartbeat checks run inside the existing authoritative process.

Before a public v0.8 release, rerun the complete dependency-backed test suite with pinned `ws`, Babylon and TypeScript versions, then redo browser/device verification for the new replicated Xam state and preview rendering.
