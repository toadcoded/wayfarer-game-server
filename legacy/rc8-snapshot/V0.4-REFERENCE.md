# Wayfarer v0.4 — reference consolidation and playable scaffold

A completed v0.4 **scaffold release**, not a production MMORPG. Builds on the intact v0.3 world kit. Nine supplied archives were extracted into isolated folders and compared by SHA-256. No uploaded install, migration, authentication, deployment or database scripts were executed.

## Run locally

Requires Node 22+ (verified on Node 24.19.0).

```sh
npm ci --ignore-scripts
npm test
npm run preview
```

Open http://127.0.0.1:8080. Compiled JavaScript is included, so `npm run preview` also works without installing dependencies. Tap terrain to choose a route, use arrow keys, or choose Cross bridge. Select Willowglass, Saffron or Mothlight. The preview binds to localhost only. It has no account, backend connection, telemetry or external asset requirement.

## Release contents

- `src/`, `dist/`: v0.3 terrain, construction, navigation and protocol plus v0.4 adapters, session authority and preview client.
- `preview/`: responsive canvas interface, schematic minimap, route overlay and inspection text.
- `reference-source/`: 159 gameplay source files from nine archives, separated by origin. These are reference material, excluded from compilation and not automatically loaded. Preserve source ownership and any upstream license requirements before redistribution.
- `audit/sources.json`: package hashes and selected-file provenance.
- `audit/archive-inventory.json`: all 69,175 extracted file hashes and paths, including dependencies; this inventory contains metadata, not file contents.
- `audit/branch-comparison.json`: pairwise source equivalence, changed paths and unique files.
- `MERGE-REPORT.md`: decisions, compatibility gaps and verified scope.
- `test/`: automated behavior tests. `audit/test-results.txt`: actual run output.

The original uploads and v0.3 directory were preserved. The full unpacked archives live beside this project in `references/`; the release includes selected gameplay sources instead of duplicating roughly 1.8 GB of dependencies and build outputs. Full extraction is reproducible with the original nine ZIPs: place them in `upload/`, run `python3 audit/unpack.py` from a separate empty working directory. The script expects `audit/` to exist (it does in this package).

## Integration contracts

World coordinates use X/Z for the ground plane and Y for elevation. `adapters/coordinates` exposes explicit grid frames; Ashfen pixel Y must be supplied as Z. Rebasing changes scale and origin, not map geometry or gameplay semantics. It does not turn a source map into a compatible live map.

`WorldSession` is transport-neutral. A host must authenticate connections, own spawn selection and call `tick()` at 20 Hz. Pass connection identity separately to `receive`; never trust a player ID from a packet. Per-connection input budgets and strict movement decoding are included. The browser preview runs this authority locally for demonstration. It is not a remote authoritative server.

## Verification and limits

Strict TypeScript compilation and automated tests cover the retained v0.3 behaviors, all reference grid cell round trips, invalid coordinates, projection inverses, preference normalization, session isolation, flood limits, snapshot copies, and all three crossings with preview prop collisions. A stubbed canvas/DOM smoke test checks preview boot, style switching, resize and movement ticks. This is not a real-browser visual test.

Browser visual QA could not run: the available Playwright runtime lacked Chromium and its browser download failed. Mobile layout, hit testing and rendering still need real-device review. Canvas uses a basic painter ordering and always draws the player above scenery; it is a reference renderer, not production 3D. The minimap depicts the crossing route, not a full terrain atlas.

Not implemented in this release: hosted multiplayer transport, durable accounts/saves, remote interpolation/reconciliation, inventory and combat integration, quests, imported map generation, production rendering, authentication migration, audio playback, full streaming world or deployment. Audio preference data is preserved; it is not an audio engine.

The detailed v0.3 guides remain in CONSTRUCTION.md, WALKING.md, CREATIVE_ATLAS.md and V0.3-REFERENCE.md.
